1.1 Clasificación de las estructuras de datos

Una estructura de datos es una forma particular de organizar y almacenar datos en una computadora para que puedan ser usados de manera eficiente. Según su organización se clasifican principalmente en:

Tipo Características Ejemplos
Lineales Los elementos se organizan de forma secuencial. Cada elemento tiene un único predecesor y un único sucesor (excepto extremos). Arrays, Listas, Pilas, Colas
No lineales Los elementos se organizan de forma jerárquica o en red. Un elemento puede tener varios predecesores o sucesores. Árboles, Grafos
Estáticas Tamaño fijo definido en tiempo de compilación o al crear la estructura. No crecen ni se reducen. Arrays / vectores
Dinámicas Tamaño variable. Crecen o se reducen en tiempo de ejecución según se necesite. Listas enlazadas, Árboles, Grafos
💡 Tip En Python las listas (list) son dinámicas y redimensionables, mientras que las tuplas (tuple) y los arrays de NumPy de tamaño fijo se comportan más como estructuras estáticas.

Ejemplo: Clasificación en código

# Estructura lineal estática (simulada con lista de tamaño fijo)
capacidad = 5
vector = [None] * capacidad   # tamaño fijo

# Estructura lineal dinámica
lista_dinamica = []           # crece según se necesite
lista_dinamica.append(10)
lista_dinamica.append(20)

print("Vector estático:", vector)
print("Lista dinámica:", lista_dinamica)

1.2 Tipos de datos abstractos (TDA)

Un Tipo de Dato Abstracto (TDA) es un modelo matemático que define un conjunto de datos y las operaciones que se pueden realizar sobre ellos, sin especificar cómo se implementan internamente.

La idea clave es la abstracción y el encapsulamiento: el usuario del TDA solo conoce la interfaz (qué operaciones puede hacer), no la representación interna de los datos.

Componentes de un TDA

  1. Dominio: el conjunto de valores posibles.
  2. Operaciones: las funciones o métodos que se pueden aplicar.
  3. Axiomas / precondiciones: reglas que deben cumplirse.
📌 En programación orientada a objetos Un TDA se implementa típicamente como una clase. Los atributos representan el estado interno y los métodos representan las operaciones públicas.

1.3 Ejemplos de TDA’s

Veamos un TDA simple: una Pila (Stack) definida de forma abstracta.

OperaciónDescripción
crear()Crea una pila vacía
apilar(x)Inserta el elemento x en el tope
desapilar()Elimina y devuelve el elemento del tope
cima()Devuelve el elemento del tope sin eliminarlo
esta_vacia()Indica si la pila no tiene elementos

Implementación simple de un TDA Pila en Python

class Pila:
    """TDA Pila implementado con una lista de Python."""
    
    def __init__(self):
        self._elementos = []          # representación interna (privada)
    
    def apilar(self, x):
        self._elementos.append(x)
    
    def desapilar(self):
        if self.esta_vacia():
            raise IndexError("La pila está vacía")
        return self._elementos.pop()
    
    def cima(self):
        if self.esta_vacia():
            raise IndexError("La pila está vacía")
        return self._elementos[-1]
    
    def esta_vacia(self):
        return len(self._elementos) == 0
    
    def __len__(self):
        return len(self._elementos)


# Uso del TDA
p = Pila()
p.apilar(10)
p.apilar(20)
p.apilar(30)
print("Cima:", p.cima())          # 30
print("Desapilado:", p.desapilar())  # 30
print("¿Vacía?", p.esta_vacia())  # False

1.4 Manejo de memoria

1.4.1 Memoria estática

El tamaño se conoce en tiempo de compilación (o al crear el objeto) y no cambia. Ejemplo clásico: un arreglo de tamaño fijo. 

# Simulación de memoria estática en Python
CAPACIDAD = 8
arreglo = [0] * CAPACIDAD   # reserva fija de 8 enteros

def insertar_estatico(arreglo, valor, posicion):
    if 0 <= posicion < len(arreglo):
        arreglo[posicion] = valor
    else:
        raise IndexError("Posición fuera de rango")

insertar_estatico(arreglo, 42, 3)
print(arreglo)

1.4.2 Memoria dinámica

La memoria se solicita y libera en tiempo de ejecución. En lenguajes como C/C++ se usa malloc/new y free/delete. En Python el manejador de memoria (garbage collector) se encarga automáticamente. 

# Memoria dinámica: la lista crece según se necesite
dinamica = []
for i in range(5):
    dinamica.append(i * 10)   # cada append puede reasignar memoria interna
print(dinamica)

# También podemos reducir
dinamica.pop()
print("Después de pop:", dinamica)
⚠️ Ventajas y desventajas
  • Estática: acceso muy rápido (O(1)), pero desperdicia memoria si no se usa toda la capacidad.
  • Dinámica: usa solo la memoria necesaria, pero las operaciones de inserción/eliminación pueden ser más costosas y hay overhead de punteros.

1.5 Análisis de algoritmos

El análisis de algoritmos nos permite predecir el comportamiento de un programa en términos de tiempo y espacio (memoria) en función del tamaño de la entrada (n).

1.5.1 Complejidad en el tiempo

Se expresa con la notación Big-O (O grande), que indica el orden de crecimiento del tiempo de ejecución en el peor caso.

NotaciónNombreEjemplo típico
O(1)ConstanteAcceso a un índice de arreglo
O(log n)LogarítmicaBúsqueda binaria
O(n)LinealRecorrer una lista
O(n log n)Lineal-logarítmicaMerge sort, Quicksort promedio
O(n²)CuadráticaBurbuja, selección
O(2ⁿ)ExponencialAlgunos algoritmos recursivos ingenuos

Ejemplo: medir tiempo de dos algoritmos

import time

def suma_lineal(n):
    """Suma de 1 a n – O(n)"""
    total = 0
    for i in range(1, n + 1):
        total += i
    return total

def suma_constante(n):
    """Fórmula de Gauss – O(1)"""
    return n * (n + 1) // 2

n = 10_000_000

inicio = time.perf_counter()
r1 = suma_lineal(n)
t1 = time.perf_counter() - inicio

inicio = time.perf_counter()
r2 = suma_constante(n)
t2 = time.perf_counter() - inicio

print(f"Lineal  → resultado={r1}, tiempo={t1:.6f}s")
print(f"Constante → resultado={r2}, tiempo={t2:.6f}s")

1.5.2 Complejidad en el espacio

Mide la cantidad de memoria adicional que necesita el algoritmo en función de n. Un algoritmo que solo usa unas cuantas variables auxiliares es O(1) en espacio; uno que crea una lista del tamaño de la entrada es O(n).

1.5.3 Eficiencia de los algoritmos

La eficiencia combina tiempo y espacio. En la práctica se busca el mejor equilibrio según el problema (a veces se prefiere más memoria para ganar velocidad).
