1.1 Clasificación de las estructuras de datos

Una estructura de datos es una forma particular de organizar, almacenar y manipular datos en la memoria de una computadora, de manera que se puedan usar de forma eficiente. La elección de la estructura correcta depende de las operaciones que se necesiten realizar (inserción, eliminación, búsqueda, recorrido, ordenamiento, etc.).

A Criterios de clasificación

Las estructuras de datos se clasifican según varios criterios independientes:

📏

Por linealidad

Lineales vs No lineales. Indica si los elementos forman una secuencia o una jerarquía/red.

📐

Por tamaño en memoria

Estáticas vs Dinámicas. Indica si el tamaño se fija en tiempo de compilación o puede cambiar en ejecución.

🔢

Por tipo de dato

Homogéneas vs Heterogéneas. Todos los elementos del mismo tipo o de tipos distintos.

🔗

Por forma de acceso

Acceso secuencial, directo o por clave (hash).

B Estructuras lineales vs no lineales

📐 Estructuras lineales

Los elementos se organizan en una secuencia: cada elemento tiene un predecesor y un sucesor (excepto extremos).

Ejemplos

  • Arreglos (arrays / vectores)
  • Listas enlazadas (simples, dobles, circulares)
  • Pilas (stacks) — LIFO
  • Colas (queues) — FIFO
[A] → [B] → [C] → [D] → [E]
Lista / Arreglo (secuencia)

🌳 Estructuras no lineales

Los elementos se organizan en jerarquías o redes. Un elemento puede tener varios predecesores o sucesores.

Ejemplos

  • Árboles (binarios, AVL, B-trees, heaps)
  • Grafos (dirigidos, no dirigidos, ponderados)
  • Tablas hash (en algunos contextos se consideran no lineales)
    [A]
  /     \
[B]     [C]
/ \       /
[D][E]   [F]
Árbol binario

C Estructuras estáticas vs dinámicas

Característica Estáticas Dinámicas
Tamaño Fijo en tiempo de compilación (o creación) Puede crecer o reducirse en tiempo de ejecución
Memoria Reserva de bloque contiguo (stack o data segment) Asignación en heap (malloc, new, etc.)
Acceso Generalmente acceso directo por índice O(1) Puede requerir recorrido O(n) (listas enlazadas)
Ventajas Rápidas, predecibles, sin sobrecarga de punteros Flexibles, usan solo la memoria necesaria
Desventajas Desperdicio o falta de espacio si el tamaño es incorrecto Sobrecarga de gestión, posible fragmentación
Ejemplos Arreglos estáticos, matrices fijas Listas enlazadas, árboles, vectores dinámicos
💡 Nota importante En lenguajes como Python, las “listas” (list) son en realidad arreglos dinámicos (vectores redimensionables). En C/C++ un arreglo clásico es estático, mientras que std::vector o listas con punteros son dinámicos.

D Homogéneas vs heterogéneas

Homogéneas

Todos los elementos son del mismo tipo de dato.

  • Arreglo de enteros: int a[10]
  • Lista de cadenas: List<String>
  • Matriz de flotantes

Heterogéneas

Los elementos pueden ser de tipos distintos.

  • Registros / estructuras (struct, class)
  • Tuplas en Python: (1, "hola", 3.14)
  • Objetos con atributos de distintos tipos

E Cuadro sinóptico resumido

ESTRUCTURAS DE DATOS
├── Lineales
│   ├── Estáticas → Arreglos / Vectores fijos
