5. Métodos de ordenamiento

Ordenar datos es una de las operaciones más frecuentes en computación. Estudiamos algoritmos internos (todo cabe en memoria principal) y externos (usan memoria secundaria / archivos).

Subtemas

  • 5.1 Algoritmos de ordenamiento internos

5.1 Algoritmos de ordenamiento internos

5.1.1 Burbuja (Bubble Sort)

Compara pares adyacentes e intercambia si están en el orden incorrecto. Muy simple pero ineficiente: O(n²).

def burbuja(lista):
    n = len(lista)
    for i in range(n):
        intercambio = False
        for j in range(0, n - i - 1):
            if lista[j] > lista[j + 1]:
                lista[j], lista[j + 1] = lista[j + 1], lista[j]
                intercambio = True
        if not intercambio:          # optimización: ya está ordenada
            break
    return lista

print(burbuja([64, 34, 25, 12, 22, 11, 90]))

5.1.2 Quicksort

Divide y vencerás. Elige un pivote, particiona el arreglo y ordena recursivamente. Promedio O(n log n), peor caso O(n²). 

def quicksort(lista):
    if len(lista) <= 1:
        return lista
    pivote = lista[len(lista) // 2]
    menores = [x for x in lista if x < pivote]
    iguales = [x for x in lista if x == pivote]
    mayores = [x for x in lista if x > pivote]
    return quicksort(menores) + iguales + quicksort(mayores)

print(quicksort([64, 34, 25, 12, 22, 11, 90]))

Versión in-place (más eficiente en memoria)

def quicksort_inplace(lista, bajo=0, alto=None):
    if alto is None:
        alto = len(lista) - 1
    if bajo < alto:
        pivote = particionar(lista, bajo, alto)
        quicksort_inplace(lista, bajo, pivote - 1)
        quicksort_inplace(lista, pivote + 1, alto)
    return lista

def particionar(lista, bajo, alto):
    pivote = lista[alto]
    i = bajo - 1
    for j in range(bajo, alto):
        if lista[j] <= pivote:
            i += 1
            lista[i], lista[j] = lista[j], lista[i]
    lista[i + 1], lista[alto] = lista[alto], lista[i + 1]
    return i + 1

5.1.3 Shell Sort

Mejora de inserción directa. Compara elementos separados por un “gap” que se reduce progresivamente.

def shell_sort(lista):
    n = len(lista)
    gap = n // 2
    while gap > 0:
        for i in range(gap, n):
            temp = lista[i]
            j = i
            while j >= gap and lista[j - gap] > temp:
                lista[j] = lista[j - gap]
                j -= gap
            lista[j] = temp
        gap //= 2
    return lista

print(shell_sort([64, 34, 25, 12, 22, 11, 90]))

5.1.4 Radix Sort

Ordena enteros dígito a dígito (por posiciones). No compara elementos entre sí. Complejidad O(d · (n + k)) donde d es el número de dígitos. 

def counting_sort_por_digito(lista, exp):
    n = len(lista)
    salida = [0] * n
    conteo = [0] * 10
    
    for i in range(n):
        indice = (lista[i] // exp) % 10
        conteo[indice] += 1
    
    for i in range(1, 10):
        conteo[i] += conteo[i - 1]
    
    for i in range(n - 1, -1, -1):
        indice = (lista[i] // exp) % 10
        salida[conteo[indice] - 1] = lista[i]
        conteo[indice] -= 1
    
    for i in range(n):
        lista[i] = salida[i]

def radix_sort(lista):
    if not lista:
        return lista
    maximo = max(lista)
    exp = 1
    while maximo // exp > 0:
        counting_sort_por_digito(lista, exp)
        exp *= 10
    return lista

print(radix_sort([170, 45, 75, 90, 802, 24, 2, 66]))

5.2 Algoritmos de ordenamiento externos

Cuando los datos no caben en memoria principal se utilizan algoritmos que trabajan con archivos o bloques. La idea principal es dividir, ordenar en memoria y luego fusionar (merge).

5.2.1 Intercalación (Merge simple)

Fusiona dos (o más) secuencias ya ordenadas en una sola secuencia ordenada.

def intercalacion(a, b):
    """Fusiona dos listas ordenadas."""
    resultado = []
    i = j = 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            resultado.append(a[i])
            i += 1
        else:
            resultado.append(b[j])
            j += 1
    resultado.extend(a[i:])
    resultado.extend(b[j:])
    return resultado

print(intercalacion([1, 3, 5, 7], [2, 4, 6, 8, 10]))

5.2.2 Mezcla Directa (Direct Merge)

Divide el archivo en bloques de tamaño 1, 2, 4, 8…, ordena cada bloque y luego los fusiona sucesivamente hasta obtener el archivo completo ordenado. 

def mezcla_directa(lista):
    """Simulación de mezcla directa en memoria (para entender el algoritmo)."""
    n = len(lista)
    ancho = 1
    while ancho < n:
        for i in range(0, n, 2 * ancho):
            izquierda = lista[i:i + ancho]
            derecha = lista[i + ancho:i + 2 * ancho]
            lista[i:i + 2 * ancho] = intercalacion(izquierda, derecha)
        ancho *= 2
    return lista

print(mezcla_directa([38, 27, 43, 3, 9, 82, 10]))

5.2.3 Mezcla Natural

Aprovecha las secuencias ya ordenadas (runs) que existen de forma natural en los datos. Suele requerir menos pasadas que la mezcla directa cuando hay orden parcial.

📌 Nota práctica En Python real, para archivos grandes se usa el módulo heapq.merge o se implementan runs con archivos temporales. En este curso nos centramos en la lógica.
