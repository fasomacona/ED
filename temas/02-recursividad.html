2. Recursividad

La recursividad es una técnica poderosa donde una función se llama a sí misma para resolver un problema. Es especialmente útil en estructuras no lineales (árboles y grafos) y en algoritmos de “divide y vencerás”.

Subtemas

  • 2.1 Definición
  • 2.2 Procedimientos recursivos
  • 2.3 Ejemplos de casos recursivos

2.1 Definición

Una función es recursiva cuando se define en términos de sí misma. Toda función recursiva debe tener:

  1. Caso base (condición de salida): el caso más simple que se resuelve directamente.
  2. Caso recursivo: reduce el problema a una versión más pequeña del mismo problema.
📌 Analogía Imagina las muñecas rusas (matrioskas): cada muñeca contiene una más pequeña hasta llegar a la más pequeña (caso base).

Estructura general

def funcion_recursiva(parametro):
    if condicion_de_parada:          # caso base
        return valor_base
    else:
        # trabajo + llamada recursiva con problema más pequeño
        return funcion_recursiva(parametro_reducido)

2.2 Procedimientos recursivos

En la práctica, la recursión se implementa mediante la pila de llamadas (call stack). Cada llamada guarda su propio contexto (variables locales y dirección de retorno).

Ventajas

  • Código más limpio y cercano a la definición matemática del problema.
  • Ideal para problemas que se dividen naturalmente (árboles, backtracking, divide y vencerás).

Desventajas

  • Puede consumir mucha memoria de pila (riesgo de stack overflow).
  • A veces es más lenta que la versión iterativa equivalente.
  • Más difícil de depurar si no se controlan bien los casos base.
⚠️ Importante Siempre asegúrate de que cada llamada recursiva se acerque al caso base. Si no lo hace, la recursión será infinita.

2.3 Ejemplos de casos recursivos

Ejemplo 1: Factorial

n! = n × (n-1)!    con   0! = 1

def factorial(n):
    if n == 0 or n == 1:          # caso base
        return 1
    return n * factorial(n - 1)   # caso recursivo

print(factorial(5))   # 120
print(factorial(0))   # 1

Ejemplo 2: Serie de Fibonacci

F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)

def fibonacci(n):
    if n == 0:
        return 0
    if n == 1:
        return 1
    return fibonacci(n - 1) + fibonacci(n - 2)

# Cuidado: esta versión es O(2^n) – muy lenta para n grandes
for i in range(10):
    print(f"F({i}) = {fibonacci(i)}")
💡 Mejora con memoización 
from functools import lru_cache

@lru_cache(maxsize=None)
def fib_rapido(n):
    if n < 2:
        return n
    return fib_rapido(n - 1) + fib_rapido(n - 2)

print(fib_rapido(40))   # instantáneo

Ejemplo 3: Torres de Hanoi

Mover n discos de la torre A a la torre C usando la torre B como auxiliar, respetando la regla de no poner un disco grande sobre uno más pequeño. 

def hanoi(n, origen, auxiliar, destino):
    if n == 1:
        print(f"Mover disco 1 de {origen} a {destino}")
        return
    hanoi(n - 1, origen, destino, auxiliar)
    print(f"Mover disco {n} de {origen} a {destino}")
    hanoi(n - 1, auxiliar, origen, destino)

hanoi(3, "A", "B", "C")

Ejemplo 4: Suma de una lista (recursiva)

def suma_lista(lista):
    if not lista:                 # caso base: lista vacía
        return 0
    return lista[0] + suma_lista(lista[1:])

print(suma_lista([1, 2, 3, 4, 5]))   # 15
