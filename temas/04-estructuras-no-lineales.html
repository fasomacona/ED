4. Estructuras no lineales

Las estructuras no lineales permiten representar relaciones jerárquicas (árboles) o de red (grafos). Son fundamentales para modelar problemas del mundo real más complejos.

Subtemas

  • 4.1 Árboles
  • 4.2 Grafos

4.1 Árboles

Un árbol es una estructura jerárquica de nodos conectados por aristas, sin ciclos. Existe un nodo especial llamado raíz.

4.1.1 Clasificación de árboles

  • Árbol general: cada nodo puede tener cualquier número de hijos.
  • Árbol binario: cada nodo tiene como máximo dos hijos (izquierdo y derecho).
  • Árbol binario de búsqueda (ABB): para cada nodo, los valores del subárbol izquierdo son menores y los del derecho mayores.
  • Árbol balanceado (AVL, Rojo-Negro): mantiene altura equilibrada para garantizar O(log n).
  • Montículo (Heap): árbol binario completo con propiedad de orden (min o max).

Nodo de árbol binario

class NodoArbol:
    def __init__(self, valor):
        self.valor = valor
        self.izq = None
        self.der = None

4.1.2 Operaciones básicas sobre árboles binarios

Árbol binario de búsqueda – inserción y búsqueda

class ABB:
    def __init__(self):
        self.raiz = None
    
    def insertar(self, valor):
        self.raiz = self._insertar(self.raiz, valor)
    
    def _insertar(self, nodo, valor):
        if nodo is None:
            return NodoArbol(valor)
        if valor < nodo.valor:
            nodo.izq = self._insertar(nodo.izq, valor)
        elif valor > nodo.valor:
            nodo.der = self._insertar(nodo.der, valor)
        return nodo
    
    def buscar(self, valor):
        return self._buscar(self.raiz, valor)
    
    def _buscar(self, nodo, valor):
        if nodo is None or nodo.valor == valor:
            return nodo
        if valor < nodo.valor:
            return self._buscar(nodo.izq, valor)
        return self._buscar(nodo.der, valor)

Recorridos de un árbol binario

def inorden(nodo):
    """Izquierda → Raíz → Derecha  (en ABB produce orden ascendente)"""
    if nodo:
        inorden(nodo.izq)
        print(nodo.valor, end=" ")
        inorden(nodo.der)

def preorden(nodo):
    """Raíz → Izquierda → Derecha"""
    if nodo:
        print(nodo.valor, end=" ")
        preorden(nodo.izq)
        preorden(nodo.der)

def postorden(nodo):
    """Izquierda → Derecha → Raíz"""
    if nodo:
        postorden(nodo.izq)
        postorden(nodo.der)
        print(nodo.valor, end=" ")

4.1.3 Aplicaciones de los árboles

  • Sistemas de archivos (directorios).
  • Árboles de decisión y de expresión.
  • Índices en bases de datos (B-trees).
  • Huffman coding (compresión).
  • Inteligencia artificial (árboles de juego).

Ejemplo completo de uso

arbol = ABB()
for v in [50, 30, 70, 20, 40, 60, 80]:
    arbol.insertar(v)

print("Inorden:", end=" ")
inorden(arbol.raiz)          # 20 30 40 50 60 70 80

print("\n¿Existe 40?", arbol.buscar(40) is not None)  # True
print("¿Existe 99?", arbol.buscar(99) is not None)  # False

4.2 Grafos

Un grafo G = (V, E) está formado por un conjunto de vértices V y un conjunto de aristas E que conectan pares de vértices. Pueden ser dirigidos o no dirigidos, ponderados o no ponderados.

4.2.1 Representación de grafos

  • Matriz de adyacencia: matriz |V| × |V|. Buena para grafos densos.
  • Lista de adyacencia: diccionario o lista de listas. Buena para grafos dispersos.

Representación con lista de adyacencia (Python)

from collections import defaultdict

class Grafo:
    def __init__(self, dirigido=False):
        self.ady = defaultdict(list)
        self.dirigido = dirigido
    
    def agregar_arista(self, u, v, peso=1):
        self.ady[u].append((v, peso))
        if not self.dirigido:
            self.ady[v].append((u, peso))
    
    def mostrar(self):
        for vertice in self.ady:
            print(f"{vertice}: {self.ady[vertice]}")

4.2.2 Operaciones básicas y recorridos

BFS – Recorrido en anchura

from collections import deque

def bfs(grafo, inicio):
    visitados = set()
    cola = deque([inicio])
    visitados.add(inicio)
    orden = []
    
    while cola:
        actual = cola.popleft()
        orden.append(actual)
        for vecino, _ in grafo.ady[actual]:
            if vecino not in visitados:
                visitados.add(vecino)
                cola.append(vecino)
    return orden

DFS – Recorrido en profundidad

def dfs(grafo, inicio, visitados=None):
    if visitados is None:
        visitados = set()
    visitados.add(inicio)
    orden = [inicio]
    for vecino, _ in grafo.ady[inicio]:
        if vecino not in visitados:
            orden.extend(dfs(grafo, vecino, visitados))
    return orden

Algoritmo de Dijkstra (camino mínimo)

import heapq

def dijkstra(grafo, origen):
    dist = {v: float('inf') for v in grafo.ady}
    dist[origen] = 0
    pq = [(0, origen)]          # (distancia, vértice)
    
    while pq:
        d_actual, u = heapq.heappop(pq)
        if d_actual > dist[u]:
            continue
        for v, peso in grafo.ady[u]:
            nueva = d_actual + peso
            if nueva < dist[v]:
                dist[v] = nueva
                heapq.heappush(pq, (nueva, v))
    return dist

Ejemplo de uso de grafos

g = Grafo(dirigido=False)
g.agregar_arista("A", "B", 4)
g.agregar_arista("A", "C", 2)
g.agregar_arista("B", "C", 1)
g.agregar_arista("B", "D", 5)
g.agregar_arista("C", "D", 8)
g.agregar_arista("C", "E", 10)
g.agregar_arista("D", "E", 2)

print("BFS desde A:", bfs(g, "A"))
print("DFS desde A:", dfs(g, "A"))
print("Distancias desde A:", dijkstra(g, "A"))
