💻 Parte práctica — Jupyter Notebook

Esta sección contiene ejercicios prácticos alineados con las actividades de aprendizaje del Tema 1. El notebook está listo para ejecutarse en Jupyter Notebook, JupyterLab, Google Colab o VS Code.

1 Cómo usar el notebook

Opción A — Local

  1. Clona o descarga este repositorio.
  2. Instala Jupyter si no lo tienes: 
    pip install jupyter
  3. Abre el notebook: 
    jupyter notebook notebooks/practica_tema1.ipynb

Opción B — Google Colab

  1. Sube el archivo practica_tema1.ipynb a Google Drive.
  2. Ábrelo con Google Colab (clic derecho → Abrir con → Colaboratory).
  3. Ejecuta las celdas en orden.

⬇️ Descargar practica_tema1.ipynb

2 Contenido del notebook

Ejercicio 1 — Clasificación de estructuras

Identificar y clasificar estructuras de datos según linealidad, tamaño y homogeneidad.

Ejercicio 2 — Implementar un TDA (Pila)

Implementar el TDA Pila con operaciones push, pop, top, is_empty y size. Probarlo con casos de uso.

Ejercicio 3 — Memoria estática vs dinámica

Comparar un vector de capacidad fija con una lista dinámica de Python. Observar qué ocurre al superar la capacidad y medir el crecimiento.

Ejercicio 4 — Análisis de complejidad

Implementar búsqueda lineal y búsqueda binaria. Medir tiempos reales con time.perf_counter para distintos tamaños de entrada y elaborar un cuadro comparativo.

Ejercicio 5 — Reto integrador

Diseñar un TDA simple (por ejemplo, una Cola o un Conjunto) eligiendo representación estática o dinámica, justificar la decisión e indicar la complejidad de cada operación.

3 Criterios de evaluación sugeridos

Criterio Peso Descripción
Correctitud del código 40 % Las operaciones del TDA y los algoritmos funcionan según la especificación.
Análisis de complejidad 25 % Se identifica correctamente Big-O y se justifica.
Comparación y conclusiones 20 % Cuadros comparativos claros y conclusiones coherentes.
Claridad y estilo 15 % Código legible, comentarios y nombres significativos.

4 Prácticas del programa de la asignatura

El programa oficial sugiere (entre otras) las siguientes prácticas relacionadas con el Tema 1:

  • Desarrollar una aplicación donde se utilicen TDA para comprobar el comportamiento estático y dinámico.
  • Identificar la eficiencia de dos algoritmos distintos que resuelven un mismo problema y elaborar un cuadro comparativo.

El notebook cubre estos puntos de forma guiada y extensible.
