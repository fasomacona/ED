3. Estructuras lineales

Las estructuras lineales organizan los datos de forma secuencial. En este tema estudiaremos pilas, colas y listas enlazadas, tanto con representación estática (arreglos) como dinámica (nodos/referencias).

3.1 Pilas (Stack)

Una pila es una estructura LIFO (Last In, First Out): el último elemento que entra es el primero que sale. Piensa en una pila de platos.

3.1.1 Representación en memoria

  • Estática: con un arreglo de tamaño fijo y un índice tope.
  • Dinámica: con una lista enlazada o la lista de Python.

3.1.2 Operaciones básicas

OperaciónDescripciónComplejidad
push / apilarInserta en el topeO(1)
pop / desapilarElimina y devuelve el topeO(1)
peek / cimaConsulta el tope sin eliminarO(1)
isEmpty¿Está vacía?O(1)

Implementación con arreglo (estática)

class PilaEstatica:
    def __init__(self, capacidad=10):
        self.capacidad = capacidad
        self.datos = [None] * capacidad
        self.tope = -1                    # índice del último elemento
    
    def apilar(self, x):
        if self.tope + 1 == self.capacidad:
            raise OverflowError("Pila llena")
        self.tope += 1
        self.datos[self.tope] = x
    
    def desapilar(self):
        if self.esta_vacia():
            raise IndexError("Pila vacía")
        valor = self.datos[self.tope]
        self.datos[self.tope] = None
        self.tope -= 1
        return valor
    
    def cima(self):
        if self.esta_vacia():
            raise IndexError("Pila vacía")
        return self.datos[self.tope]
    
    def esta_vacia(self):
        return self.tope == -1

# Prueba
p = PilaEstatica(5)
p.apilar("A")
p.apilar("B")
print(p.desapilar())   # B

Implementación dinámica (recomendada en Python)

class Pila:
    def __init__(self):
        self._items = []
    
    def apilar(self, x):
        self._items.append(x)
    
    def desapilar(self):
        if not self._items:
            raise IndexError("Pila vacía")
        return self._items.pop()
    
    def cima(self):
        return self._items[-1]
    
    def esta_vacia(self):
        return len(self._items) == 0

3.1.3 Aplicaciones de las pilas

  • Evaluación de expresiones (notación postfija).
  • Balanceo de paréntesis / corchetes.
  • Historial de navegación (atrás).
  • Llamadas a funciones (call stack).
  • Deshacer (undo) en editores.

Ejemplo: verificar paréntesis balanceados

def parentesis_balanceados(expresion):
    pila = []
    pares = {')': '(', ']': '[', '}': '{'}
    for car in expresion:
        if car in '([{':
            pila.append(car)
        elif car in ')]}':
            if not pila or pila[-1] != pares[car]:
                return False
            pila.pop()
    return len(pila) == 0

print(parentesis_balanceados("((a+b)*[c-d])"))   # True
print(parentesis_balanceados("((a+b])"))         # False

3.2 Colas (Queue)

Una cola es FIFO (First In, First Out): el primero que llega es el primero que sale. Como la fila del cine.

3.2.1 – 3.2.2 Representación y operaciones

OperaciónDescripciónComplejidad
enqueue / encolarInserta al finalO(1)*
dequeue / desencolarElimina del frenteO(1)*
front / frenteConsulta el frenteO(1)

* Con implementación circular o collections.deque

Implementación simple (lista)

from collections import deque

class Cola:
    def __init__(self):
        self._items = deque()          # más eficiente que list.pop(0)
    
    def encolar(self, x):
        self._items.append(x)
    
    def desencolar(self):
        if not self._items:
            raise IndexError("Cola vacía")
        return self._items.popleft()
    
    def frente(self):
        return self._items[0]
    
    def esta_vacia(self):
        return len(self._items) == 0

3.2.3 Tipos de colas

  • Simple: FIFO clásico.
  • Circular: el final se conecta con el inicio (aprovecha el espacio del arreglo).
  • Bicola (Deque): se puede insertar y eliminar por ambos extremos.
  • De prioridad: los elementos salen según su prioridad, no solo por orden de llegada.

Cola circular (con arreglo)

class ColaCircular:
    def __init__(self, capacidad):
        self.capacidad = capacidad
        self.datos = [None] * capacidad
        self.frente = 0
        self.final = -1
        self.tamano = 0
    
    def encolar(self, x):
        if self.tamano == self.capacidad:
            raise OverflowError("Cola llena")
        self.final = (self.final + 1) % self.capacidad
        self.datos[self.final] = x
        self.tamano += 1
    
    def desencolar(self):
        if self.tamano == 0:
            raise IndexError("Cola vacía")
        valor = self.datos[self.frente]
        self.frente = (self.frente + 1) % self.capacidad
        self.tamano -= 1
        return valor

3.2.4 Aplicaciones

  • Cola de impresión / procesos del sistema operativo.
  • Simulación de filas (banco, restaurante, aeropuerto).
  • BFS (recorrido en anchura de grafos).
  • Buffers de datos.

3.3 Listas enlazadas

Una lista enlazada es una secuencia de nodos donde cada nodo contiene un dato y una referencia (puntero) al siguiente nodo. No requiere memoria contigua.

Nodo básico

class Nodo:
    def __init__(self, dato):
        self.dato = dato
        self.siguiente = None

Lista simplemente enlazada

class ListaSimple:
    def __init__(self):
        self.cabeza = None
    
    def insertar_inicio(self, dato):
        nuevo = Nodo(dato)
        nuevo.siguiente = self.cabeza
        self.cabeza = nuevo
    
    def insertar_final(self, dato):
        nuevo = Nodo(dato)
        if not self.cabeza:
            self.cabeza = nuevo
            return
        actual = self.cabeza
        while actual.siguiente:
            actual = actual.siguiente
        actual.siguiente = nuevo
    
    def eliminar(self, dato):
        if not self.cabeza:
            return
        if self.cabeza.dato == dato:
            self.cabeza = self.cabeza.siguiente
            return
        actual = self.cabeza
        while actual.siguiente and actual.siguiente.dato != dato:
            actual = actual.siguiente
        if actual.siguiente:
            actual.siguiente = actual.siguiente.siguiente
    
    def mostrar(self):
        actual = self.cabeza
        elementos = []
        while actual:
            elementos.append(str(actual.dato))
            actual = actual.siguiente
        print(" → ".join(elementos) if elementos else "Lista vacía")

# Uso
lista = ListaSimple()
lista.insertar_final(10)
lista.insertar_final(20)
lista.insertar_inicio(5)
lista.mostrar()          # 5 → 10 → 20
lista.eliminar(10)
lista.mostrar()          # 5 → 20

Tipos de listas

  • Simplemente enlazada: cada nodo apunta solo al siguiente.
  • Doblemente enlazada: cada nodo tiene puntero al anterior y al siguiente.
  • Circular: el último nodo apunta de nuevo al primero.
